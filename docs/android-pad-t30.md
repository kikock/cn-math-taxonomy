# 科大讯飞 T30 平板 Android 版（Capacitor 6 离线内嵌架构）说明文档

## 1. 概述与产物信息

本工程为《中小学·高中知识图谱（cn-math-taxonomy）》面向 **科大讯飞 AI 学习机 T30 系列（T30 Pro / T30 Ultra，14.7 英寸 3024×2016 3:2 类纸护眼屏）** 打造的独立离线 Android 客户端。

* **已编译签名安装包路径**：`dist/cn-math-taxonomy-pad-t30-v1.0.0.apk`
* **安装包大小**：**4.90 MB**（已内嵌数学、语文、英语、物理、化学、生物、历史、地理、道法、科学全部 10 个学科的完整图谱、课标与诊断题库，100% 离线免联网运行）
* **应用包名 (Application ID)**：`com.cnmath.taxonomy.pad`
* **签名规范**：RSA-2048 正式证书，同时开启 V1 (JAR) + V2 (Full APK) + V3 签名，兼容 Android 7.0 ~ Android 15（含讯飞 T30 搭载的 Android 12 系统）。

## 2. 科大讯飞 T30 专项适配能力清单

### 2.1 14.7 英寸 3K (3:2) 大屏与类纸护眼视觉系统 (`assets/pad-t30.css`)
1. **类纸暖光护眼配色 (`data-eyecare="paper"`)**：针对 T30 纳米/微纳米类纸屏漫反射特性，默认采用低眩光暖宣纸色背景 (`#f5f2e9`) 与高对比度墨色文字 (`#1c2026`)，可在顶栏一键切换「类纸护眼 / 标准明亮」。
2. **三档视距字号 (`data-font-scale="std|lg|xl"`)**：针对平板桌面支架 40~50cm 端坐视距，默认采用大字号 (`19px`)，支持在顶栏一键切换「标准字 / 大字 / 特大字」，同时按钮与选项卡片最小触控热区扩大至 `56px`。
3. **诊断页「左题右草稿」双栏工作台 (`.diagnose-workbench`)**：
   * 在 T30 横屏 (`1512×1008 dp`) 下，答题界面自动展开为 **左侧 52% 题目与选项区 + 右侧 48% 星闪手写笔演算草稿本**。
   * 草稿本容器 (`#scratchpad-pane`) 与题目渲染容器 (`#root`) 解耦并列，学生在左侧点选选项或查看解析时，右侧手写演算笔迹 100% 保持不丢失。

### 2.2 第三代星闪 AI 手写笔 120Hz 压感演算草稿本 (`assets/scratchpad.js`)
1. **硬件级压感与 120Hz 高刷低延迟**：
   * 原生 `MainActivity.java` 启动时自动枚举并激活屏幕最高刷新率（120Hz）；
   * 画布开启 `{ desynchronized: true }` 低延迟直接上屏通道，结合 `PointerEvent.getCoalescedEvents()` 高频采样与二次贝塞尔曲线插值，笔迹线宽随星闪笔压力 (`event.pressure`) 连续平滑变化。
2. **智能防手掌误触（Palm Rejection）**：
   * 默认开启「防误触：开」。一旦识别到星闪手写笔 (`pointerType === 'pen'`) 落笔，自动屏蔽手掌贴屏产生的 `touch` 触摸干扰。
3. **理科专属底纹与矢量撤销栈**：
   * 支持一键切换 **方格纸**（辅助列竖式/对齐小数）、**平面直角坐标系**（辅助函数与几何画图）、**空白纸**。
   * 采用轻量级矢量笔迹指令流保存历史，支持 30 步撤销/重做，屏幕旋转或全屏切换时无损重绘；进入下一题时自动清空上一题草稿。

### 2.3 平板内联数学小键盘与学习机儿童纯净模式 (`assets/platform.js`)
1. **免弹系统输入法的内联数学小键盘**：针对数值填空题，在题目下方直接内嵌包含 `0~9`、`分数 /`、`负号 -`、`小数点 .`、`百分号 %`、`π` 的大按键面板，避免系统软键盘弹出遮挡半个屏幕。
2. **学习机儿童纯净模式 (`pure-study-mode`)**：
   * 默认隐藏并移除顶部外链横幅、趣味测评卡片、网盘资源搜索按钮及 GitHub 外链；
   * 全局拦截任何指向外部域名的链接点击，杜绝在学习机受控环境下跳出失败或触发管控报警。
3. **原生沙盒双写与返回键状态机**：
   * 孩子档案与诊断历史在写入 `localStorage` 的同时，自动镜像备份至 Android 原生 `DATA` 沙盒目录（`cnm_children_native_backup.json`），防止系统清理缓存导致档案丢失；
   * 接管安卓边缘侧滑返回手势：优先关闭分享弹窗/退出草稿全屏 $\rightarrow$ 子页面返回首页 $\rightarrow$ 首页双击返回键退出应用。

## 3. 一键复现构建与测试指令

### 运行全量单元测试（共 146 项断言）
```powershell
npm test
```

### 重新构建离线资产与签名 APK
```powershell
npm run build:apk
```
构建完成后，最新签名的安装包会自动输出至 `dist/cn-math-taxonomy-pad-t30-v1.0.0.apk`。
